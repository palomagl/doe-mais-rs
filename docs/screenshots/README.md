# Capturas de tela

Imagens usadas no `README.md` da raiz. Salve os prints com **exatamente** estes nomes:

| Arquivo | Tela |
| --- | --- |
| `dashboard.png` | Dashboard — status de doação, impacto e atalhos |
| `hero-gameplay.png` | DOE+ Hero — gameplay (a Corrida pela Vida) |

Opcional, se quiser mostrar mais telas depois (adicione a `<img>` correspondente no README):

| Arquivo | Tela |
| --- | --- |
| `hemocentros.png` | Lista de hemocentros do RS |
| `quiz.png` | Quiz de elegibilidade |
| `hero-mapa.png` | DOE+ Hero — mapa de fases |

Como gerar: `npm run dev`, abra `http://localhost:8080`, deixe o navegador com largura ~390px (modo dispositivo) e tire o print.
